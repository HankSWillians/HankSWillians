## 🚀 Proyecto destacado

### [CoffeeScale](https://github.com/HankSWillians/Coffeescale)
Sistema IoT de reabastecimiento de inventario: básculas digitales reportan el peso de cada saco de café y, cuando baja del umbral, el sistema genera automáticamente una orden de compra hacia el ERP.

- **Arquitectura:** 7 funciones AWS Lambda, orientada a eventos con SQS, hexagonal en el núcleo del dominio
- **Seguridad:** telemetría firmada con HMAC-SHA256, secretos en Parameter Store, IAM de mínimo privilegio, CI/CD con OIDC
- **Calidad:** pruebas unitarias y de integración, análisis SAST/SCA con Bandit, Semgrep y pip-audit, alarmas en CloudWatch

`Python` `AWS Lambda` `SQS` `DynamoDB` `API Gateway` `SAM` `GitHub Actions` `Node.js`
